# ParkingMAS

**ParkingMAS** project for the *Distributed Systems* and *Intelligent Systems Engineering* courses.

## Description

ParkingMAS is a **distributed Multi-Agent System** that models a parking system. Drivers are located in a city divided
into areas, each containing several parking lots with limited spots. Drivers can autonomously move through the city and
search for, enter, and exit parking lots.

## How to run

After cloning the repository, you can run the project by executing the following command from the project root:

```bash
./runParkingMAS.sh
```
